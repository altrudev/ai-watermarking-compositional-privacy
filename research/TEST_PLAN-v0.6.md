# Provenance Linkability / Non-Commutativity Mechanism Test Plan v0.6

**Status:** predeclared synthetic-only protocol  
**Research phase:** v0.6  

## Research purpose

v0.4 established transformation path dependence in one controlled synthetic benchmark. v0.5 tested robustness and preserved a negative condition in which the order effect disappeared.

v0.6 does not ask whether order matters again. It asks **which state changes make transformation order matter, which attribution channels are changed by reversing a pair, and whether those pairwise effects predict the complete four-transform path outcome.**

## DDC research boundary

### Authority

The experiment is authorized only over identities and text generated by the existing synthetic harness.

### Prohibited expansion

v0.6 does not ingest real people, accounts, provider logs, conversations, scraped profiles, private datasets, external identity corpora, production watermark detectors, or proprietary translation/model APIs.

### Standing evidence rules

- Privacy transformation ≠ privacy evidence.
- Failed re-identification ≠ proven anonymity.
- Synthetic benchmark mechanism ≠ deployed-provider mechanism.
- Pairwise predictor success ≠ universal privacy law.
- Predictor failure is a valid result and must be preserved.

## Fixed predecessor

The experiment is based on the canonical v0.5 lineage and uses the existing v0.3/v0.5 transformation and attribution primitives without modifying their historical files.

Canonical predecessor experiment: `43d4b97a1c9b53a73de079ac166134fba663f494`.

## Population and transformations

Reference population:

- 12 synthetic persons;
- 144 synthetic generation events;
- canonical seed 41;
- canonical publication-artifact seed 7000;
- all publication artifacts evaluated.

Privacy-relevant transformations:

1. paraphrase;
2. summarize;
3. translate proxy;
4. model-edit proxy.

All six unordered transform pairs are evaluated in both orders.

## T1 — Pairwise state non-commutativity

For each unordered pair `{A, B}` compare:

`A → B`

against

`B → A`.

Measure:

- fraction of artifact texts that differ;
- final metadata equality;
- lexical-vector divergence;
- semantic-vector divergence;
- style-vector divergence.

This identifies whether reversing the pair changes final observable state and through which declared feature families.

## T2 — Pairwise attribution consequence

For both orders of each pair, measure:

- combined person top-1 attribution;
- combined generation top-1 attribution;
- lexical-only person attribution;
- semantic-only person attribution;
- style-only person attribution;
- watermark-only person attribution;
- timing-only person attribution.

Record the signed and absolute attribution difference when the order reverses.

## T3 — Channel-mechanism map

For each pair, identify the channel with the largest absolute attribution change under order reversal.

The experiment must preserve zero and adverse findings; it must not report only pairs whose order effect is large.

## T4 — Full-path pairwise predictor

Evaluate all 24 permutations of the four transformations using the existing combined attribution policy.

Construct a predictor from pairwise ordering effects only:

1. for every ordered pair relation `A before B`, use the signed pairwise person-attribution effect measured in T2;
2. for each full four-transform path, sum the effects corresponding to its six pairwise ordering relations;
3. compare that pairwise score with the path's observed final person top-1 attribution.

Primary prediction metric: Pearson correlation across all 24 paths.

Predeclared interpretation:

- `r >= 0.70`: **PAIRWISE_MECHANISM_PREDICTIVE_FOR_DECLARED_TEST**;
- `0.30 <= r < 0.70`: **PARTIAL_PAIRWISE_EXPLANATION**;
- `r < 0.30`: **PAIRWISE_MECHANISM_NOT_PREDICTIVE**.

The threshold is declared before the v0.6 reference result is generated and must not be changed after observing the result.

## T5 — Commuting negative control

Compare:

`lowercase → normalize whitespace`

with

`normalize whitespace → lowercase`.

Required negative-control conditions:

- final text equality: true;
- final metadata equality: true;
- person-attribution difference: 0;
- generation-attribution difference: 0.

If this control fails, the v0.6 mechanism claim is not supported.

## T6 — Determinism and regression

- repeat reference run must be byte-equivalent as JSON after key sorting;
- existing v0.3/v0.4/v0.5 files are not modified;
- all identity-bearing IDs remain in the `syn-` namespace;
- Python compilation and v0.6 tests must pass before merge.

## Reference claim gate

The harness may emit only one of:

- `PAIRWISE_MECHANISM_PREDICTIVE_FOR_DECLARED_TEST`
- `PARTIAL_PAIRWISE_EXPLANATION`
- `PAIRWISE_MECHANISM_NOT_PREDICTIVE`
- `CONTROL_FAILED`

It must not emit `ANONYMOUS`, `UNTRACEABLE`, `GENERAL_LAW`, or a deployed-provider claim.

## Interpretation boundary

A positive result would support a bounded mechanism claim inside this synthetic benchmark: that measurable pairwise non-commutativity explains a substantial portion of full-path attribution variation.

A negative result would be equally important: it would show that higher-order interaction among three or more transformations is necessary to explain the observed path dependence.
